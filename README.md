# 금융공학의 이해

**무차익과 복제의 논리**  
김주철 · 연세대학교

이 저장소는 『금융공학의 이해』의 **공개 배포 전용 저장소**입니다.
완성된 PDF와 책에서 공개하기로 한 동반 계산·재현 코드만 제공합니다.

## 파일

- `금융공학의_이해.pdf` — B5(182×257 mm) 공개 PDF
- `code/` — 계산 실습 및 제17장 딥헤징 재현 코드
- `code/results/` — 책에 사용한 제17장 고정 재현 결과

코드 실행법과 기준 환경은 [`code/README.md`](code/README.md)를 참고하십시오.

## 공개 범위

이 공개 저장소에는 LaTeX 원고, 조판 소스, 내부 CI/리뷰 자료 등 제작용 파일은 포함하지 않습니다.
공개 PDF와 동반 코드는 같은 공개판을 기준으로 관리합니다.

## 저작권

별도의 라이선스가 명시되지 않은 한 PDF와 코드의 저작권은 저자에게 있습니다.
이 저장소의 공개는 열람과 계산 재현을 위한 접근 제공이며, 별도의 이용허락을 의미하지 않습니다.
